## 🧰 Service Directory | دليل الخدمات

The service catalog consolidates the unique services found in the repository's previous website versions. Repeated entries are merged, while one-off services are retained.

يجمع دليل الخدمات الخدمات الفريدة الموجودة في نسخ الموقع القديمة. تم دمج العناصر المتكررة مع الاحتفاظ بالخدمات التي ظهرت مرة واحدة فقط.

### Main categories | التصنيفات الرئيسية

1. **Digital manufacturing:** 3D printing, CAD and modeling, prototyping, laser engraving and cutting.  
   **التصنيع الرقمي:** الطباعة ثلاثية الأبعاد، التصميم والنمذجة الهندسية، النماذج الأولية، النقش والقطع بالليزر.
2. **Electronics & PCB:** Single/double-layer PCB design, fabrication, soldering, diagnostics and repair.  
   **الإلكترونيات وPCB:** تصميم PCB بطبقة أو طبقتين، التصنيع، اللحام، التشخيص والإصلاح.
3. **Energy:** Solar power banks, device charging, batteries and power management.  
   **الطاقة:** بنوك الطاقة الشمسية، شحن الأجهزة، البطاريات وإدارة الطاقة.
4. **Mobility electronics:** Bicycle, motorcycle and car lighting, horns, dynamos, audio and suitable solar charging.  
   **إلكترونيات المركبات:** أنوار وكلاكس ودينامو وصوت للدراجات والموتوسيكلات والسيارات وحلول شحن شمسي مناسبة.
5. **Software:** Website, application and game development; computer software troubleshooting.  
   **البرمجيات:** تطوير المواقع والتطبيقات والألعاب وتشخيص مشكلات برمجيات الكمبيوتر.
6. **Networks:** Local network setup, access/security basics and router configuration. Cisco, CCBOOT, CCOFE and GIZMO are listed as planned expansion areas.  
   **الشبكات:** إعداد الشبكات المحلية وإدارة الوصول والحماية الأساسية وإعداد الراوتر. خدمات Cisco وCCBOOT وCCOFE وGIZMO مدرجة كتوسعات مخططة.
7. **Embedded systems & R&D:** Arduino, Raspberry Pi, sensors, robotics, automation and AI experiments.  
   **الأنظمة المدمجة والبحث والتطوير:** Arduino وRaspberry Pi والحساسات والروبوتات والأتمتة وتجارب الذكاء الاصطناعي.

> **Status note | تنبيه الحالة:** The directory describes the project's service scope and roadmap. Planned and R&D items are not a promise that every service is commercially available today.  
> يوضح الدليل نطاق المشروع وخطته. الخدمات المخططة ومجالات البحث والتطوير لا تعني أن جميعها متاحة تجاريًا في الوقت الحالي.

## 🚀 Run Locally | التشغيل محليًا

Language files load through `fetch`, so use a local HTTP server rather than opening the HTML file directly.

`python -m http.server 8000`

Then open `http://localhost:8000`.

يتم تحميل ملفات اللغات باستخدام `fetch`، لذلك شغّل الموقع عبر خادم محلي بدل فتح ملف HTML مباشرة.

**EN:**
